## Changes

- Latest Updates: Vibe 2.26.0. The entry covers the changes that affect users,
  not every item in the release notes. The Unified Harness no longer silently
  falls back to the legacy engine. The `~/.vibe/.env` key fallback is now
  created `0600`. The notes do not say that existing files are re-permissioned,
  so the entry warns about keys saved by earlier versions. The Rust CLI now sends
  client usage telemetry, and the entry names the documented switch
  (`enable_telemetry = false`, from the Vibe README). The release notes describe
  the Rust CLI as selected by `VIBE_CLI`, with the Python TUI as legacy. The
  entry does not claim which interface is the default.
- Mistral Compute: mistral.ai has a new top-level navigation (Research,
  Sovereign AI, Cloud, Customers, Company). `/products/ai-cloud/`, adopted on
  2026-10-02, now returns 404, and `/products/aicloud/` and
  `/products/mistral-compute` redirect to that 404. The products page links
  [`/cloud/compute/`](https://mistral.ai/cloud/compute/) ("AI Cloud for training
  and inference at scale"), which returns 200 and describes reserved GPU
  capacity in Europe. The README now links it. The new
  [`/cloud/inference/`](https://mistral.ai/cloud/inference/) page presents the
  existing API under the "Mistral Cloud" name and is not a new product. The
  2026-10-02 audit's link to the old URL is now plain text, since that audit is
  part of the same unmerged PR.
- Star snapshots: 17 badges had drifted a bucket since the last refresh and were
  set from `audit_github.py` (Ollama from the GitHub API). RocketRide went from
  8k+ (2026-09-08) to 17,873 stars. That pace is unusual, but the repository is
  active, with 325 issues and PRs from many contributors since 2026-09-08 and
  its README advertises no star or fork campaign. The badge reflects the
  measured count. Its stargazer API returned 404, so the star timeline could not
  be inspected.
- Flagship-table snapshot date moved to 2026-10-06; contents unchanged.
- Link exceptions: the 2026-10-04 scheduled run measured HTTP 403 from the
