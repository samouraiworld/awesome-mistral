Source notes:

- The previous audit's 52B vs 49B active-parameter conflict is resolved by the
  [weight card](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B):
  49B active per token, 52B including embeddings and output layers. The README
  now gives both. The API card still says 1.05T total; the weight card says ~1T.
- The Ecosystem license is not the revenue-restricted Modified MIT used by
  Medium 3.5, Devstral 2 and Timestral. It instead requires a separate commercial
  license for licensees or affiliates operating a Model-as-a-Service business,
  with exemptions for internal use and use through Mistral's products. The
  README explains the difference rather than grouping both as "Modified MIT".
- The Hugging Face weight repository was created 2026-09-30 and the NVFP4
  repository 2026-10-15; creation dates do not establish public release, so the
  announcement date is used. Both are ungated (API `gated: false`).

  was not treated as a primary paper; no Research entry cites it.
