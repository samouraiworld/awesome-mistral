### Documented source conflict: Shieldstral parameter count

Three official sources disagree, so the conflict is recorded rather than resolved
silently, per the sources-of-record rule in MAINTENANCE.md:

- The Hugging Face model card prose and the repository name
  ([Shieldstral-1.0-3B](https://huggingface.co/mistralai/Shieldstral-1.0-3B)) say **3B**,
  reflecting its `Ministral-3-3B-Base-2512` base model.
- The official documentation
  [schema](https://github.com/mistralai/platform-docs-public/blob/main/src/schema/models/models/shieldstral-1-0.ts)
  states `parameters: '3.8'` and `metadata: { parameters: '3.8B total and active' }`.
- The Hugging Face API reports a safetensors total of **3,849,090,048** parameters.

The schema and the tensor count agree; the difference is the native Pixtral vision
encoder carried on top of the 3B base. The README now states 3.8B total, the
figure supported by two independent sources, while keeping the vendor's own
`-3B` repository URL. The catalog schema's weights URL
(`mistralai/Shieldstral-1.0`) resolves by HTTP 307 to that same repository.
