## Security boundaries and limits

This repository initially contained no application runtime, package manifest,
model weights or dependency lockfile. The actionable security surface was GitHub
permissions, workflow supply chain, untrusted links and repository governance.
The new Python checks use the standard library, bounded subprocess calls and
argument arrays; the metadata collector only calls GitHub for public metadata.
The check does not execute linked software or model code.

No third-party project received a full source security audit. A successful link
response and a recent push do not establish software safety or complete model
compatibility. The X account's ownership is corroborated by the official Mistral
documentation footer, but its authenticated content/accessibility is not verified.
That exception expires 2026-09-11 and must be reviewed weekly. The first PR run
also encountered GitHub-runner-only 403s on two Reddit community URLs; each
returned HTTP 200 from the maintenance host. Both have exact CI exceptions with
the failed-run evidence and the same weekly expiry.
